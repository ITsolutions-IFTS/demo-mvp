Código

Setup en 5 minutos

Todo el stack corre en el navegador. Solo necesitás HTTPS para acceder a la cámara.

ar-experience.html (core) 
<!-- 1. Cargar librerías -->
<script src="aframe.min.js"></script>
<script src="ar.min.js"></script>

<!-- 2. Escena AR -->
<a-scene
  embedded
  arjs="trackingMethod: best;">

  <!-- 3. Modelo 3D sobre el marcador -->
  <a-marker preset="hiro">
    <a-entity
      gltf-model="#mi-producto"
      scale="0.5 0.5 0.5"
      position="0 0.5 0"
      animation="property: rotation;
        to: 0 360 0; loop: true;
        dur: 6000">
    </a-entity>
  </a-marker>

  <a-entity camera></a-entity>
</a-scene>
  • 1
    Cloná el repo Todos los archivos ya están incluidos. No hay dependencias de Node.js ni build process.
  • 2
    Subí a GitHub Pages Settings → Pages → Deploy from branch main. GitHub genera HTTPS automáticamente (obligatorio para acceder a la cámara).
  • 3
    Imprimí el marcador Hiro Abrí marker.html en el repo y hacé print. O descargá el PNG para enviarlo por WhatsApp.
  • 4
    Cambiá el modelo 3D Reemplazá modelo.glb con tu propio archivo GLTF/GLB. Podés descargar modelos gratis de sketchfab.com o poly.pizza.
  • 5
    Probá en el celular Chrome en Android o Safari iOS 12+. Apuntá la cámara al marcador impreso.
Tecnología

Stack 100% open source

Cero licencias. Cero backend. Corre directo en el navegador del cliente.

🅰
A-Frame
Framework WebXR declarativo. Escenas 3D con HTML tags.
📍
AR.js
Tracking de marcadores en el navegador. Usa ARToolKit compilado a WASM.
🎲
Three.js
Motor 3D WebGL subyacente. Rendering de modelos GLTF/GLB.
📦
GLTF / GLB
Formato 3D estándar. Modelos gratuitos en Sketchfab, Poly Pizza, Google Scans.
⚡
GitHub Pages
Hosting gratuito con HTTPS incluido. Deploy automático desde el repo.
